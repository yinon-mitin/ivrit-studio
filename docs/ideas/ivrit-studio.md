# Ivrit Studio — «Ivrit Cheatsheet» + тренажёр для курса (уровень Алеф)

> **2026-10-20: разворот.** Проект стал веб-шпаргалкой без тренажёра: Блиц, прогресс, Anki, еженедельные файлы и правило «один экран» убраны; добавлены части, поиск, «скрыть перевод» и печать. Актуальный контракт — `SPEC.md`, план — `tasks/plan.md`. Ниже — исходная идея, оставлена для истории.

## Problem Statement
Как сделать так, чтобы ученик уровня Алеф через месяц **читал печатный и прописной иврит с огласовками без запинок**, имея под рукой шпаргалку, где каждый раздел помещается на один экран, а материал каждой недели курса попадал туда за минуты и почти без токенов?

## Для кого и что считается успехом
- **Для кого:** я и одногруппники (ссылка в чате группы).
- **Языки перевода:** английский основной, русский дополнительный (как в материалах курса).
- **Успех через месяц:** читаю печатные и прописные буквы с огласовками без запинок.
- **Устройства:** телефон и ноутбук одинаково. Прогресс хранится локально на каждом устройстве и переносится между ними экспортом и импортом.
- **Главное ограничение:** минимум токенов на разработку и на еженедельную поддержку.

## Recommended Direction
**Статический сайт без сборки** (HTML + ванильный JS-модули, GitHub Pages). **Каждый раздел — это файл данных** с двумя режимами:
- **«Шпаргалка»:** справка, которая помещается на один экран без прокрутки и свайпов. Большой раздел делится на подвкладки, которые переключаются тапом.
- **«Блиц»:** карточки и выбор ответа. Сайт запоминает ошибки и чаще показывает то, что легко спутать (ה/ח/ת, ד/ר, ו/ז/ן, ס/ם, ב/כ, бет с дагешем и без). Каждый раздел можно скачать как TSV и импортировать в Anki.

Главное архитектурное правило — **меняются только данные, код никогда**. Новый раздел или материал недели = новый JSON-файл. Еженедельное добавление — это «агенту дают схему и сводку от учительницы (docx из чата группы), он выдаёт JSON»: примерно 3–5 тыс. токенов, без чтения кодовой базы. Шрифты (печатный и прописной) лежат файлами в репозитории, без CDN. Флаги — эмодзи, они ничего не весят. Озвучки нет. Без фреймворка нет и обновлений зависимостей, так что сайт остаётся лёгким: HTML, JS, данные и два файла шрифтов.

## Шрифты
Оба шрифта есть в каталоге Google Fonts под лицензией **SIL OFL 1.1**. Эта лицензия разрешает выкладывать файлы шрифта в свой репозиторий и раздавать их с сайта.

| Роль | Шрифт | Почему |
|---|---|---|
| **Печатный** (и интерфейс) | **Heebo** (Oded Ezer, на основе Roboto) | Один из самых используемых шрифтов иврита в вебе. Огласовки встают правильно (проверено рендером `שָׁלוֹם, מַה שְּׁלוֹמֵךְ? בְּבַיִת`). Есть латиница. **Кириллицы нет** (проверено), поэтому русский текст автоматически набирается системным шрифтом: `font-family: Heebo, system-ui, sans-serif`. Это бесплатно и ничего не весит |
| **Прописной** | **Gveret Levin** (AlefAlefAlef) | Настоящая школьная пропись (כתב יד), единственный популярный открытый шрифт такого рода. Поддерживает огласовки, это редкость для прописи |

Отвергнутые варианты:
- **Dana Yad** — бесплатный, но лицензия AlefAlefAlef запрещает распространять файлы без разрешения, то есть класть его в публичный репозиторий нельзя.
- **Ktav Yad CLM** (Culmus) — лицензия GPL, но огласовки не отображаются, а начертание грубее.
- **Frank Ruhl Libre** — запасной печатный вариант с засечками, «как в книгах и газетах», если Heebo покажется слишком упрощённым.

Перед публикацией оба шрифта переводятся в `woff2` и урезаются до нужных символов (иврит с огласовками, латиница, пунктуация). Ожидаемо это десятки килобайт на шрифт, точно измерим при сборке. Рядом лежит файл `OFL.txt`, как требует лицензия.

## Хостинг: GitHub Pages
- Чистая статика из ветки `main`, без GitHub Actions и без Jekyll (файл `.nojekyll` в корне).
- Поэтому **данные хранятся в JSON, а не в YAML**: браузер разбирает JSON сам, а для YAML понадобилась бы библиотека или шаг сборки.
- Сайт на `*.github.io` открыт всем, у кого есть ссылка, даже если репозиторий приватный. Учебных материалов из учебника там не будет (см. «Not Doing»), а от поисковиков закрываемся тегом `<meta name="robots" content="noindex">`.

Общие для всех разделов функции: переключатель **«с огласовками / без»** (по умолчанию с огласовками), светлая и тёмная тема (по системе + переключатель), переключатель EN/RU.

**Прогресс:** ошибки и статистика Блица хранятся в `localStorage`. Есть экран «Прогресс» с двумя кнопками:
- **Экспорт:** скачать JSON-файл или скопировать его как текст (удобно переслать себе в мессенджер с телефона на ноутбук).
- **Импорт:** загрузить файл или вставить текст. Данные **сливаются** с текущими, а не затирают их: по каждой карточке остаётся более свежая запись. Так можно заниматься на обоих устройствах попеременно.

В файле прогресса есть поле `version`, чтобы будущие изменения формата не ломали старые экспорты. В файле недели есть поле `letters:` («буквы, пройденные к этой неделе»), так что Блиц не забегает вперёд курса.

## Разделы
| Раздел | Шпаргалка (один экран) | Блиц | Заметки |
|---|---|---|---|
| **Алфавит** | Сетка 5×6: печатная буква крупно (Heebo), под ней прописная (Gveret Levin), название и транслитерация | печатная ↔ прописная ↔ название | 22 буквы + 5 конечных + בּ כּ פּ שׁ שׂ. Отдельный режим: строка печатных над строкой прописных для тренировки чтения прописи |
| **Огласовки** | Знак на примере (בַּ בֶּ בִּ בּוֹ בּוּ בְּ…) + транслитерация | слог → чтение | Пары, которые звучат одинаково: камац/патах, сегол/цере |
| **Цвета** | Цветная плашка + 4 формы (`אדום / אדומה / אדומים / אדומות`) | цвет + существительное → нужная форма | Тренирует заодно и согласование по роду |
| **Дни недели** | `יום ראשון` … `שבת` | день ↔ название | Показать логику: дни — это порядковые номера, «первый день» = воскресенье |
| **Месяцы** | Григорианские: `ינואר` … `דצמבר` | месяц ↔ название | Заимствования, отличная практика чтения. Еврейский календарь не включаем |
| **Муж → Жен / Ед → Мн** | Таблицы: `תלמיד/תלמידה/תלמידים/תלמידות`, `גר/גרה`, `מדבר/מדברת/…`, `זה/זאת/אלה`, исключения (`אישה → נשים`) | выбор окончания | Пополняется из файлов недели |
| **Приветствия и small talk** | Фраза с огласовками + м.р./ж.р. + EN/RU | «к кому обращаются?» по огласовкам (`מה שלומךָ / שלומךְ`), различение `מה שמך / מה שלומך` | Пополняется из файлов недели |
| **Страны и языки** | Флаг-эмодзи + страна + язык(и); 6 подвкладок по регионам (список ниже) | флаг → страна → язык | Языки на `-ית` (`צרפת → צרפתית`), ~75 стран. Связь с правилом `מִ/מֵ` + страна |
| **Чупчик (גֶּרֶשׁ) и двойной вав** | Таблица звуков: `ג׳` = дж, `צ׳` = ч, `ז׳` = ж; `וו` = в/w в заимствованиях | слово латиницей/кириллицей → как пишется | `סרג'יו`, `צ'ילה` (страна) vs `צ'ילי` (перец), `וודקה`, `וואטסאפ` / `ווטסאפ`, `ג'ינס`, `ז'נבה`, `צ'יפס` |

Названия стран — устоявшиеся заимствования. Их ивритское написание сверяется по ивритской Википедии, огласовки — через Dicta Nakdan.

Порядок разработки задаёт критерий успеха: **Алфавит → Огласовки → разделы с заимствованиями (Страны, Месяцы, Чупчик) → Цвета/Дни → Род/Число → Приветствия**.

## Key Assumptions to Validate
- [ ] **Огласовки корректны.** В разделах около 350 записей на иврите (из них ~75 стран и ~45 языков). Каждую прогонять через Dicta Nakdan, сомнительные показывать учительнице. Это главная цена проекта, а не код.
- [ ] **Gveret Levin достаточно похож на почерк учительницы.** Сравнить с фото доски или раздатки.
- [ ] **Шрифты остаются лёгкими после урезания до нужных символов.** Измерить размер `woff2` при первой сборке.
- [ ] **Каждый вид помещается на экран 390×844 (телефон) и 1280×720 (ноутбук).** Проверить вёрсткой алфавита первым: это самый плотный раздел.
- [ ] **Ручной перенос прогресса не раздражает.** Неделю заниматься на двух устройствах с экспортом и импортом. Если переносить лень, значит, прогресс на втором устройстве не так уж важен, и это тоже ответ.
- [ ] **Флаги-эмодзи приемлемы.** В Windows вместо флага видны две буквы (`IL`, `FR`). Проверить, мешает ли это группе.
- [ ] **Группа будет пользоваться.** Скинуть ссылку в чат и через неделю спросить, кто открывал.

## MVP Scope
**Входит:** движок «раздел = данные → Шпаргалка + Блиц», учёт ошибок, экспорт и импорт прогресса (файл/текст, слияние), экспорт в Anki (TSV), переключатели огласовок/темы/языка, разделы **Алфавит, Огласовки, Страны, Чупчик**, файл недели 11 октября, встроенные шрифты Heebo и Gveret Levin (`woff2`, урезанные), деплой на GitHub Pages, RTL.

**Следующий шаг после MVP:** Месяцы, Дни, Цвета, Род/Число, Приветствия — это просто новые файлы данных на готовом движке.

## Not Doing (and Why)
- **Аккаунты и автоматическая синхронизация.** Бэкенд — это деньги и поддержка. Перенос между устройствами решается экспортом и импортом файла.
- **Озвучка (TTS, записи).** Отложена, чтобы не утяжелять сайт и не возиться с генерацией. Если понадобится, данные уже готовы: можно будет добавить поле `audio` к записям, не трогая разделы.
- **SVG-флаги.** Лишний вес. Используем эмодзи и миримся с двухбуквенными кодами в Windows.
- **Полноценная колода Anki (.apkg) или синхронизация с Anki.** TSV-экспорт даёт почти всю пользу почти бесплатно.
- **Прокрутка и свайпы в разделах.** Если не помещается, подвкладки по тапу или меньше содержимого.
- **Еврейский календарь.** Для Алефа хватит григорианских месяцев.
- **Письмо пальцем или стилусом.** Выбрано узнавание, а распознавание почерка — отдельный большой проект.
- **Страницы недели со ссылками на видео и домашку.** Дублирует чат группы.
- **Голосовой собеседник на LLM.** Рано для Алефа, стоит токенов на каждого пользователя.
- **Фреймворк и сборка (React/Vite и т. п.).** Обновления зависимостей и больше контекста для агента.
- **Копирование упражнений из учебника.** Авторские права. Берём слова и пишем свои предложения.
- **Игровые механики, рейтинги, серии дней.** Витамин. Вернёмся, если группа подсядет.
- **Админка на сайте.** Добавление контента = JSON + коммит.
- **YAML и шаг сборки (GitHub Actions).** На GitHub Pages отдаётся чистая статика, данные в JSON.
- **Шрифты с Google Fonts/CDN.** Только файлы шрифтов в репозитории.

## Open Questions
- Репозиторий публичный или приватный? Pages для приватного репозитория требует платного плана GitHub, а сам сайт в обоих случаях открыт по ссылке.
- Нужен ли свой домен, или хватит `*.github.io`?
- Есть ли в группе страны, которых нет в списке (родные страны одногруппников)? Их стоит добавить.
